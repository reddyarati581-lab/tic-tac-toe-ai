# PROJECT REPORT
## Tic-Tac-Toe AI Using Python

### 1. Introduction
Tic-Tac-Toe is a popular two-player game played on a 3x3 board. This project allows a human player to play against an intelligent computer.

### 2. Objectives
- Develop a Tic-Tac-Toe game using Python.
- Create an intelligent computer opponent.
- Implement the Minimax algorithm.
- Detect winning and draw conditions.

### 3. Technologies Used
- Python Programming
- Artificial Intelligence
- Minimax Algorithm

### 4. Methodology
The game uses a 3x3 board. The human player uses X and the computer uses O. The computer checks possible moves using the Minimax algorithm and selects the best move.

### 5. Algorithm
1. Initialize an empty board.
2. Accept the human player's move.
3. Validate the selected position.
4. Check winning and draw conditions.
5. Calculate the computer's best move using Minimax.
6. Display the computer's move.
7. Repeat until the game ends.

### 6. Advantages
- Easy to understand.
- Intelligent computer opponent.
- Detects wins and draws.
- Demonstrates AI concepts.

### 7. Conclusion
The project demonstrates how Artificial Intelligence and the Minimax algorithm can be used to create an intelligent Tic-Tac-Toe game using Python.
