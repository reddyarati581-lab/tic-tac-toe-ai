# Tic-Tac-Toe AI

## Project Description
Tic-Tac-Toe AI is a Python-based game where a human player plays against an intelligent computer opponent.

The computer uses the Minimax algorithm to select the best possible move.

## Features
- Human vs Computer gameplay.
- 3x3 Tic-Tac-Toe board.
- Intelligent computer opponent.
- Minimax algorithm.
- Win, loss, and draw detection.
- Input validation.
- Real-time game results.

## Technologies Used
- Python 3
- Minimax Algorithm
- Artificial Intelligence
- Conditional Statements
- Functions and Lists

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

```bash
python tic_tac_toe.py
```

5. Enter a position from 1 to 9 to play.

## Game Instructions

- You play as X.
- Computer plays as O.
- Enter a number from 1 to 9.
- Get three matching symbols in a row, column, or diagonal to win.

## AI Algorithm

The Minimax algorithm evaluates possible game moves and selects the best move for the computer.
