# Tic-Tac-Toe AI Test Cases

| Test No. | Test Input / Action | Expected Result |
|---|---|---|
| 1 | Enter a valid position from 1 to 9 | X is placed in that position |
| 2 | Enter a letter instead of a number | Program asks for a valid number |
| 3 | Enter 0 or 10 | Program rejects the position |
| 4 | Choose an occupied position | Program asks the player to choose another position |
| 5 | Human creates three X marks in a row | Human win is detected |
| 6 | Computer creates three O marks in a column | Computer win is detected |
| 7 | Board is full with no winner | Draw is detected |
| 8 | Computer selects a move | Computer chooses an available position |

## Conclusion

The test cases check input validation, legal moves, winning conditions, draw detection and AI move selection.
